Before moving into reliability engineering, I worked on Vail Systems' in-house applications as a
full-stack engineer, delivering features in weekly cycles with cross-functional teams.

## What I owned

- **Features end to end:** UI in React and TypeScript, REST APIs in Node.js and Express, and the
  database design behind them, using Prisma for data access, SQL and connection pooling.
- **Production debugging:** I traced defects across the UI, API, database, container runtime and
  CI/CD layers. That's where I built the systems-level intuition my SRE work relies on.
- **Release readiness:** I improved environment configuration and container-based release
  workflows, laying groundwork for the team's later move to Kubernetes.
